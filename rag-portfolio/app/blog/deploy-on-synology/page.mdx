<p>У меня уже был NAS, который работал 24/7. Держать проект на виртуалке с Linux, развернутом на домашнем компьютере — не вариант, хотелось стабильности.</p>

</ul>

<h2>Проблемы, с которыми я столкнулся</h2>

<p>Самым сложным оказался не код, а DNS внутри Docker на Synology. Ошибка <code>EAI_AGAIN</code> не давала бэкенду достучаться до YandexGPT.</p>

<p><strong>Решение:</strong> прописал <code>extra_hosts</code> с IP-адресом в <code>docker-compose.yml</code>.</p>
